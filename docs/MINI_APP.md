# Статистика в Telegram Mini App

Тот же сервер публикует `/help`, `/privacy` и `/terms` без входа в Telegram. Кнопки в боте используют текущий `WEBAPP_URL`; дополнительный поддомен не нужен. Настройка и необязательный отдельный адрес: [публичная справка](PUBLIC_PAGES.md).

Mini App запускается вместе с `python app.py`. Использует ту же базу и правила
расчёта, что `/chatstats`. Новый сбор истории не нужен. API только читает данные.

## Настройка

1. Установите зависимости: `python -m pip install -r requirements.txt`.
2. Направьте домен, например `stats.example.com`, на сервер бота.
3. Настройте HTTPS reverse proxy на `127.0.0.1:8080`. Пример для Caddy:

   ```caddyfile
   stats.example.com {
       reverse_proxy 127.0.0.1:8080
   }
   ```

4. Добавьте в `.env`:

   ```dotenv
   WEBAPP_URL=https://stats.example.com
   WEBAPP_HOST=127.0.0.1
   WEBAPP_PORT=8080
   ```

5. Перезапустите бота, откройте `/chatstats` и нажмите «Открыть статистику».

Для контейнера или Pterodactyl: задайте `WEBAPP_HOST=0.0.0.0`, выделите порт
в панели и направьте HTTPS proxy на этот порт. Адрес приложения должен вести
на корень домена; размещение в подпапке не поддерживается.

## Доступ и интерфейс

### NimarkoHost / Pterodactyl + Cloudflare

Для выделенного адреса `node.ettacent.dev:25572` и поддомена `stats.nyaaa.moe`
можно запустить HTTPS непосредственно в приложении, без установки reverse proxy
в контейнере. Предполагается, что выделенный порт доступен снаружи по TCP
и не занят другим сервисом. У polling-бота отдельного входящего слушателя нет.

1. В Cloudflare откройте **SSL/TLS → Origin Server → Create Certificate**.
   Выпустите сертификат для `stats.nyaaa.moe`, выбрав RSA и формат PEM.
2. В панели хостинга создайте папку `ssl` рядом с `app.py` и сохраните туда
   сертификат как `origin.pem`, а private key — как `origin.key`.
   Ключ остаётся на сервере; отправлять его в чат не требуется.
3. В `.env` хостинга добавьте:

   ```dotenv
   WEBAPP_URL=https://stats.nyaaa.moe
   WEBAPP_HOST=0.0.0.0
   WEBAPP_PORT=25572
   WEBAPP_SSL_CERT=ssl/origin.pem
   WEBAPP_SSL_KEY=ssl/origin.key
   ```

4. В Cloudflare DNS добавьте **CNAME**: имя `stats`, target `node.ettacent.dev`,
   режим **Proxied** (оранжевое облако). В target не указывается порт.
   Адрес из Network может быть алиасом allocation: если DNS этого имени
   не указывает на узел хостинга напрямую, получите у поддержки фактический IP
   allocation и используйте A-запись `stats` с этим IP вместо CNAME.
5. В **Rules → Origin Rules** создайте правило:

   ```text
   (http.host eq "stats.nyaaa.moe")
   Destination port → Rewrite to → 25572
   ```

6. Для этого же hostname задайте **SSL → Full (strict)** через Configuration Rule.
   Если зона уже использует Full (strict), отдельное правило не нужно.
   Правило только для `stats.nyaaa.moe` сохраняет текущие настройки основного сайта.
7. Перед заменой кода создайте резервную копию сервера через **Backups**.
   Загрузите архив обновления и распакуйте в корень проекта с заменой файлов кода.
   Существующие `.env`, база и папка `profile_data` в архив не включены.
   Установите `requirements.txt` и перезапустите бот.
   Откройте `https://stats.nyaaa.moe`: в обычном браузере появится предложение
   открыть приложение из Telegram. Затем проверьте кнопку в `/chatstats`.

Origin CA предназначен для соединения Cloudflare → приложение. При прямом
открытии сервера или выключении Proxied браузер не доверяет такому сертификату.
Убедитесь, что Edge Certificate поддомена в Cloudflare активен. Для статистики
оставьте Cache-Control приложения без изменений; не включайте Cache Everything.

Документация Cloudflare:
[Origin Rules и доступность изменения порта](https://developers.cloudflare.com/rules/origin-rules/),
[Origin CA](https://developers.cloudflare.com/ssl/origin-configuration/origin-ca/).

## Авторизация и показатели

Сервер проверяет HMAC-подпись `Telegram.WebApp.initData`, срок авторизации
(24 часа) и права через текущие `routes`. Отзыв приглашения закрывает доступ
на следующем запросе. ID аккаунта в адресе не даёт права читать чужие данные.
Обычный браузер показывает предложение открыть приложение из бота.
Токен бота, тексты сообщений и пользовательская сессия не отправляются в браузер.

Nyan message начинается со списка чатов. Основной формат — телефон;
на компьютере открывается тот же интерфейс в более широком контейнере.
Нижняя навигация: Чаты, Сводка, Ещё. В меню «Ещё» находятся ваша активность,
рейтинги, тема, обновление и правила расчётов. В карточке чата указан конкретный аккаунт; общий
переключатель аккаунтов скрыт. Поиск и сортировка чатов сохраняются при возврате.
Периоды и выбор аккаунта применяются ко всему разделу.

В карточке четыре раздела: Общение, Ритм, Медиа, Изменения.
В «Ритме» ответы, длинные паузы и инициатива показаны одновременно;
удаления и правки также объединены. В медиа видны все типы, список слов
загружается по 50 с кнопкой догрузки. Чатовых страниц по пять строк больше нет.
График интерактивный: выбор дня касанием, наведением или ползунком;
точные значения доступны в раскрываемой таблице. За всё время график показывает
до 90 календарных дней доступной подробной истории, без пустого пространства
до первой сохранённой даты. Итоги сохраняются за весь выбранный период.

Чаты можно закрепить через меню действий карточки. Закреплённые идут первыми
в списке; есть отдельный фильтр. Выбор сохраняется на устройстве.
Действие «Скачать CSV» выгружает итоги и отображаемый подробный ряд по дням
(не более 90 дней). Это не экспорт текстов сообщений.

Светлая тема включена по умолчанию. Кнопка темы включает тёмную; выбор сохраняется
на устройстве. Для обновления нажмите «Обновить». Адрес в hash сохраняет
экран/чат/раздел, стандартная кнопка «Назад» браузера возвращает предыдущий экран.

Шрифты Nunito Sans и иконки Phosphor включены в проект и обслуживаются с
домена приложения. Описание мобильных сценариев — в MOBILE_UX.md.

После обновления дизайна замените код из архива и перезапустите бот.
DNS, правила Cloudflare, сертификат и существующий `.env` менять не нужно.

Всё время включает сохранённые старые итоги. Ограниченный период также включает
их, если он охватывает весь известный диапазон `first_at`–`last_at` чата.
Поэтому для чата с известной историей в пределах последних 30 дней итог
«30 дней» совпадает с «Всё время», даже если подробная история восстановлена
лишь частично. Старые счётчики не перезаписываются и не распределяются по дням.

Если период уже срока переписки или исходные границы неизвестны, используются
подробные сообщения и показывается предупреждение о неполной истории.
Графики, ответы и события всегда используют подробную историю. Общие медиа
и слова для периода полного охвата могут включать накопленные итоги;
разделение по авторам использует подробные данные. Раздел «Полнота данных»
показывает оба объёма, источник итогов и необработанную старую часть.
Пропуски графика не считаются нулевой активностью.
Правила расчёта также доступны внутри приложения в разделе «Об учёте».

При запуске `app.py` задаёт отображаемое имя бота **Nyan message**.
Username бота не меняется. Прикреплённая пользователем картинка используется
в интерфейсе и favicon; для изменения аватарки самого бота загрузите исходную
картинку через BotFather → `/setuserpic`.

Проверки: `python -m unittest discover -s tests`.
Для полноценной проверки запуска нужен реальный HTTPS-адрес и открытие кнопки
на устройствах с Telegram; локальные API-тесты этого не заменяют.
