# Nyan message: мобильный интерфейс

Интерфейс адаптирует Material 3 Expressive для Telegram Mini App: тональные поверхности,
связанные группы кнопок и списков, крупная типографика, разные формы для разных ролей.
Это веб-адаптация, а не нативное приложение Android. Эффект нажатия использует официальный
`@material/web` 2.5.0. Остальная компоновка выполнена на HTML/CSS, с нативными кнопками
и диалогами. React и Node.js для работы бота не нужны.

## Устройство экранов

- Чаты открываются первыми. Поиск, закреплённые чаты, сортировка по дате или сообщениям.
  В строке видны число сообщений, дата последнего общения и аккаунт, если их несколько.
- Аккаунт и период выбираются в нижних панелях. Выбранный вариант отмечен галочкой.
- В переписке: общий объём, дни общения, вклад каждого, график. Кнопка назад возвращает
  поиск, фильтр и положение списка. Длинные имена переносятся.
- В разделе «Ритм» обычное время ответа видно сразу. Остальные расчёты раскрываются
  по нажатию. Неделя и время суток идут ниже.
- Вкладки «Медиа» и «Изменения» сохраняют прежние показатели и ограничения полноты.
- Все экраны используют одну светлую или тёмную тему. По умолчанию светлая; сохранённый
  выбор устройства сохраняется. Минимальные области нажатия: 44 px.
- Лавандовая линия графика сплошная, розовая пунктирная. Точные значения доступны под
  графиком и в таблице. Неполная история отмечается; пропуски не заменяются нулями.
- Системная настройка уменьшения движения отключает анимации и ripple.

## Цвета и шрифт

Холодный светлый фон `#f8f7fc`, текст `#322a43`, лавандовый акцент `#7052a3`,
лавандовая поверхность `#e7dcfa`, пудрово-розовая поверхность `#fae2ed`, розовый текст
`#813f60`. Тёмная тема использует сливовый фон `#181420`, светлую лаванду и розовый.
Шрифт Nunito Sans хранится локально; иконки Phosphor также локальные.
Никаких новых запросов к CDN при работе интерфейса.

## Сборка Material Web

Готовый `business_tools/web/material.js` включён в проект. Для пересборки на машине
разработчика установите `@material/web@2.5.0` и `esbuild@0.28.2` в отдельной папке.
Создайте там `entry.js`:

```js
import '@material/web/ripple/ripple.js';
function attach(root) {
  root.querySelectorAll('button').forEach(button => {
    if (!button.querySelector('md-ripple')) {
      button.append(document.createElement('md-ripple'));
    }
  });
}
attach(document);
new MutationObserver(() => attach(document)).observe(document.body, {
  childList: true, subtree: true
});
```

Соберите файл через esbuild с `--bundle --minify --format=iife` и сохраните результат
в `business_tools/web/material.js`. Скрипт подключён после `app.js`, разрешён в списке
статических файлов. Лицензии Material Web, Lit и tslib находятся рядом с этим документом.

## Проверка

Проверены светлая и тёмная темы, ширины 320, 375, 430, 812 и 1440 px на демонстрационной
базе. Данные проверки вымышленные. Проверены навигация, поиск, фильтры, обе панели выбора,
закрепление, CSV, загрузка следующих слов, длинные имена, ошибки и повтор загрузки.
Проверка внутри реального Telegram выполняется после загрузки файлов на хостинг.

## Небольшие анимации

Открытие чата и переход назад: сдвиг 12 px и проявление за 200 ms. Смена вкладки
внутри чата: сдвиг 10 px в сторону выбранного раздела. Шапка и вкладки не двигаются.
График проявляется за 240 ms, полоска долей мягко раскрывается за 260 ms.
Выбранные вкладки и кнопки дают короткий отклик. Нижняя панель открывается за 300 ms,
затемнение за 200 ms. Нет зацикленных эффектов и задержки действий ради анимации.
Все программные анимации отменяются при новом запросе. При включении системного
уменьшения движения даже уже начавшиеся анимации отменяются.
