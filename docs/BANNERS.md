# Баннеры разделов

Оригинальные PNG хранятся в `assets/banners/`. Размер каждого — 1350 × 720. При подключении изображения не менялись.

| Файл | Экран |
| --- | --- |
| `menu.png` | Главное меню для пользователя с доступом |
| `invite.png` | Приветствие до получения приглашения |
| `connect.png` | Подключение Business-аккаунта |
| `status.png` | Состояние подключения |
| `notifications.png` | Уведомления, включая настройку уведомлений закрытого модуля |
| `data.png` | Данные, приватность, остановка и возобновление сбора |
| `help.png` | Помощь |
| `erase.png` | Подтверждение удаления данных |
| `rules.png` | Сохранённые приостановленные правила автоудаления |
| `private_profiles.png` | Главное меню закрытого модуля |
| `profiles.png` | Список профилей, карточка и история профиля |
| `watch.png` | Управление наблюдением |
| `events.png` | Последние изменения профилей |
| `settings.png` | Настройки закрытого модуля |

Имена файлов на сервере должны совпадать с таблицей. Для замены оформления загрузите новый PNG под тем же именем. Публичное меню отправляет короткий текст подписью к фото; длинные тексты остаются отдельным сообщением с кнопками. Существующие сообщения в Telegram не обновляются автоматически: откройте раздел заново.

Если картинка отсутствует, публичная часть отправляет текстовое меню, а закрытый модуль использует прежний баннер. Мини-приложение эти изображения не загружает.

Публичное меню и закрытый модуль используют общий кэш `file_id` внутри одного экземпляра бота. После первой успешной загрузки баннера Telegram получает идентификатор файла. При замене PNG кэш обновляется; при отказе Telegram принять старый идентификатор бот загружает файл заново. Кэш хранится в памяти и не переносится между разными ботами. Одновременные первые обращения могут загрузить один баннер несколько раз; задержка одного пользователя не блокирует меню остальных.

При нажатии кнопок публичного меню бот редактирует текущий экран. Если сообщение больше нельзя изменить, отправляет новое. Команда `/menu` открывает новый экран. Ответ «сообщение не изменилось» не создаёт копию меню. Длинный текст, который не помещается в подпись, остаётся отдельным сообщением.

Заголовки, важные предупреждения и названия кнопок в инструкциях выделены жирным. Иконки в тексте взяты из [TgAndroidIcons](https://t.me/addemoji/TgAndroidIcons). Публичное меню считает длину подписи после HTML-разметки, с запасом до лимита Telegram. Если Telegram отклонит custom emoji, меню повторяет запрос с обычными Unicode-иконками и сохраняет жирное выделение; следующие экраны этого экземпляра бота используют тот же запасной вариант. Имена аккаунтов и другие внешние значения экранируются.
