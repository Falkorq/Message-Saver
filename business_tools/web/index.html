В режиме «Все аккаунты» переписки с одним собеседником объединяются по Telegram ID. Выберите отдельный аккаунт, чтобы посмотреть один диалог.

За какой период?

Дни считаются по московскому времени. «Всё время» — сохранённая история Nyan и загруженные вами экспорты. Доступны только известные сообщения.

Старая переписка

Добавьте экспорт чата, чтобы увидеть статистику до подключения Nyan. Вход в аккаунт не нужен.

В Telegram Desktop откройте нужный чат → ⋮ → Экспорт истории чата. Выберите JSON, медиа скачивать не нужно. Максимум — 128 МБ.

Импорт добавляет только статистику, без уведомлений и архива текстов. Удалённые сообщения и прошлые версии правок из экспорта восстановить нельзя. Повторяющиеся сообщения не считаются дважды. Временный файл удаляется после обработки или через 10 минут ожидания.
